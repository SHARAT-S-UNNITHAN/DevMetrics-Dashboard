## 🎯 Features

| Feature | Description |
|---------|-------------|
| 🔐 **GitHub Login** | Simulated authentication with connected user state |
| 📈 **PR Metrics** | Track open PRs, merged PRs, and review requests |
| ⏱️ **Review Lag Chart** | Visualize first-response delays with color-coded bars |
| 🔽 **Repository Selector** | Switch between mock repos (core, ui, api, docs) |
| 🌙 **Dark/Light Mode** | Persistent theme preference with smooth transitions |
| 👥 **Team Activity Table** | Contributor breakdown with trends and status |
| 📊 **Cycle Health** | Review rates, stale PRs, approval metrics |

## 🎨 Design System

- **Glassmorphism UI** - Backdrop blur, semi-transparent cards, subtle borders
- **Data-focused layout** - KPI cards, responsive grid, accessible charts
- **Typography** - Syne for headings, JetBrains Mono for data/code
- **Accessibility** - WCAG 2.1 AA, keyboard navigation, ARIA labels
