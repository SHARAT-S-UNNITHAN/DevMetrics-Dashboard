## Features

| Feature | Description |
|---------|-------------|
| **GitHub Login** | Simulated authentication with connected user state |
| **PR Metrics** | Track open PRs, merged PRs, and review requests |
| **Review Lag Chart** | Visualize first-response delays with color-coded bars |
| **Repository Selector** | Switch between mock repos — core, ui, api, docs |
| **Dark / Light Mode** | Persistent theme preference with smooth transitions |
| **Team Activity Table** | Contributor breakdown with trends and status indicators |
| **Cycle Health** | Review rates, stale PRs, and approval metrics |

---

## Design System

- **Glassmorphism UI** — Backdrop blur, semi-transparent cards, subtle layered borders
- **Data-focused layout** — KPI cards, responsive grid, accessible Chart.js visualizations
- **Typography** — `Syne` for headings · `JetBrains Mono` for data and code
- **Accessibility** — WCAG 2.1 AA compliant, keyboard navigation, ARIA labeling

---

## Tech Stack

```yaml
Frontend:    HTML5, CSS3, Vanilla JavaScript
Charts:      Chart.js 4.4.1
Icons:       Inline SVG
Theming:     CSS Custom Properties + localStorage
Responsive:  Mobile-first Flexbox & CSS Grid
Deployment:  GitHub Pages
```
