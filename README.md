# 📊 DevMetrics Dashboard

**Open-source GitHub PR analytics tool** for engineering leads and open-source maintainers

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## ✨ Live Demo

🔗 **View Dashboard:** https://sharat-s-unnithan.github.io/DevMetrics-Dashboard/

## 🎯 Features

| Feature | Description |
|---------|-------------|
| 🔐 **GitHub Login** | Simulated authentication with connected user state |
| 📈 **PR Metrics** | Track open PRs, merged PRs, and review requests |
| ⏱️ **Review Lag Chart** | Visualize first-response delays with color-coded bars |
| 🔽 **Repository Selector** | Switch between mock repos (core, ui, api, docs) |
| 🌙 **Dark/Light Mode** | Persistent theme preference with smooth transitions |
| 👥 **Team Activity Table** | Contributor breakdown with trends and status |
| 📊 **Cycle Health** | Review rates, stale PRs, approval metrics |

## 🎨 Design System

- **Glassmorphism UI** - Backdrop blur, semi-transparent cards, subtle borders
- **Data-focused layout** - KPI cards, responsive grid, accessible charts
- **Typography** - Syne for headings, JetBrains Mono for data/code
- **Accessibility** - WCAG 2.1 AA, keyboard navigation, ARIA labels

## 🛠️ Tech Stack

```yaml
Frontend: HTML5, CSS3, Vanilla JavaScript
Charts: Chart.js 4.4.1
Icons: Inline SVG
Theming: CSS Custom Properties + localStorage
Responsive: Mobile-first Flexbox & Grid
```

## 🚀 Quick Start

### Local Development

```bash
# Clone the repository
git clone https://github.com/SHARAT-S-UNNITHAN/DevMetrics-Dashboard.git

# Navigate to project
cd DevMetrics-Dashboard

# Open in browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### GitHub Pages

The dashboard is automatically deployed at:
```
https://sharat-s-unnithan.github.io/DevMetrics-Dashboard/
```
